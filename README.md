Esta aplicação automatiza a extração de especificações de produtos registrados em uma planilha do Google Drive utilizando a API do Gemini. Para atender a diferentes contextos de uso, o repositório conta com duas abordagens:

Versão Gratuita: Desenvolvida para contornar as taxas de limite (rate limits) da versão gratuita da API. Processa uma especificação por vez e conta com tratativas de erro e controle de requisições para evitar perda de dados.

Versão Pro / Paga: Aproveita a capacidade máxima e alta velocidade da API paga, realizando a busca de múltiplas especificações do produto de forma simultânea e sem limitações severas.
